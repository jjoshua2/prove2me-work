# Finite basis-row certificates force a one-ray restricted kernel

The exact positive-circuit enumerator used in the Polynomial Hirsch experiments performs Gaussian elimination on a candidate support, checks that the restricted nullspace has one free coordinate, reconstructs a positive null vector, and normalizes it. The already-Proved circuit theorems characterize the resulting mathematical object, but an explicit certificate is still useful between an executable row reduction and those abstract circuit predicates.

Fix a linear map `A : R^n -> R^k`, a candidate vector `x`, and a pivot coordinate `j` with `x_j != 0`. For every coordinate `i` in the support of `x`, the input certificate gives a row-combination vector `dual_i`. It is checked only on the finitely many standard columns of `A`:

\[
\langle dual_i,Ae_l\rangle
 = \delta_{li} - (x_i/x_j)\delta_{lj}.
\]

By linearity, any vector `z` decomposes into its standard-coordinate expansion, so the same row combination satisfies

\[
\langle dual_i,Az\rangle = z_i-(x_i/x_j)z_j.
\]

If `Az=0`, this forces `z_i=(x_i/x_j)z_j` for every `i` where `x_i` is nonzero. If `z` is additionally supported inside `supp(x)`, all remaining coordinates of `z` vanish. Therefore

\[
z=(z_j/x_j)x.
\]

Thus the restricted signed kernel is exactly the one-dimensional line generated by `x`.

This is a certificate theorem, not a verification of a particular Python or RREF implementation. A program still has to emit/check the finite column identities honestly. Conversely, once those identities are available, no rank oracle, Farkas theorem, circuit-generation axiom, positivity assumption, bounded polyhedron, or diameter premise is needed for the one-ray conclusion. Accepted theorem `Hirsch.positive_circuit_signed_kernel_and_rank` can then connect this one-ray property to support-minimal positive circuits when the usual positivity/null assumptions on `x` are also supplied; accepted `Hirsch.normalized_positive_circuits_iff_extreme_points` connects normalized positive circuits to vertices of the nonnegative kernel section.
