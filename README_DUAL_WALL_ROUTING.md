note, an exact rational route generator/verifier, independent regression tests,
and generated route fixtures. It is an add-only continuation based on
`980681f765b7458d69aee61318dfcfcaa9e2f6af`; it does not alter PR #208.

Start with `research/DUAL_WALL_ROUTING_AND_SEPARATED_STARS_2026-09-12.md` and the
verification handoff next to it. Run `python3 scripts/test_minkowski_wall_sweep.py`.

spread-box route and 24-coordinate permutohedron route.

packages finite exposed-edge evidence, identifies a strict limitation of
proper-face target locking, and supplies the actual selected-carrier assembly.
